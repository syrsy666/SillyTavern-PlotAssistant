# 剧情辅助（SillyTavern 扩展）

在聊天输入框旁的魔法棒菜单中注册“剧情辅助”。输入剧情走向并确认后，该指令会在**下一次正常发送用户回复**时，以高优先级辅助创作模型声明的形式追加到发送内容的末尾，只生效一次。

## 安装

1. 解压压缩包，得到 `SillyTavern-PlotAssistant` 文件夹。
2. 将整个文件夹放入当前用户的 `data/<用户句柄>/extensions/` 目录；若使用全员扩展目录，也可放入 `public/scripts/extensions/third-party/`。
3. 刷新或重启 SillyTavern，在扩展管理中确认“剧情辅助”已启用。

## 使用

1. 点击输入框旁的魔法棒 → **剧情辅助**。
2. 输入本次希望 AI 遵循的剧情走向，点击**确认**。
3. 正常输入并发送下一条用户回复。插件会自动把剧情指令追加到实际发送内容的末尾，然后清空待发送状态。
4. 菜单项右侧出现绿点表示有待发送指令；再次打开可修改，也可点击**清除待发送**取消。

## 行为说明

- 不会把辅助指令写入用户消息或聊天记录。
- 不会在重新生成、换一换、角色扮演输入或后台静默生成时自动消耗指令。
- 同时兼容 Text Completion 与 Chat Completion，包括多模态消息。
- 提示词位置与强化措辞只能提高遵循概率，无法改变模型本身的安全规则，也无法保证所有模型百分之百服从。
